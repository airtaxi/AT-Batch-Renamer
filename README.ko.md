# AT Batch Renamer

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE.txt)

🌐 [English](README.md) | 한국어

AT Batch Renamer는 여러 파일과 폴더의 이름을 한 번에 변경하는 Windows 앱입니다.

변경 규칙은 트리거 목록으로 구성합니다. 텍스트 바꾸기, 번호 추가, 확장자 소문자 변환 같은 트리거를 추가하면 목록 위에서부터 순서대로 적용되며, 각 트리거는 앞 트리거가 만든 이름을 이어받아 처리합니다.

변경될 이름은 미리보기로 먼저 확인할 수 있고, 실행 후에는 되돌릴 수 있습니다.

## 주요 기능

- **트리거 조합:** 바꾸기, 추가, 대소문자 변환 트리거를 원하는 순서로 조합합니다. 드래그로 순서를 바꿀 수 있고, 체크를 해제하면 트리거를 삭제하지 않고 건너뜁니다. 트리거 목록은 `.brtriggers` 파일로 저장하고 불러올 수 있습니다.
- **실시간 미리보기와 충돌 검사:** 파일이나 트리거가 바뀔 때마다 새 이름을 다시 계산합니다. 중복 이름, 이미 존재하는 이름, 사용할 수 없는 문자, 빈 이름, `CON`·`NUL` 같은 예약 이름은 실행 전에 표시됩니다.
- **안전한 이름 변경과 되돌리기:** 모든 항목을 임시 이름으로 옮긴 뒤 최종 이름으로 변경합니다. 따라서 두 파일의 이름 맞바꾸기(`a.txt` ↔ `b.txt`), 연쇄 변경, `photo.JPG` → `photo.jpg` 같은 대소문자만의 변경도 처리할 수 있습니다. 폴더와 그 안의 파일을 함께 변경할 수 있으며, 일부 항목이 실패하면 해당 항목만 원래 이름으로 복원하고 실패 사유를 표시합니다.
- **파일 탐색기 우클릭 메뉴:** 파일이나 폴더를 선택한 뒤 우클릭 메뉴에서 **AT Batch Renamer로 이름 바꾸기**를 선택합니다. "추가 옵션 표시"를 거치지 않고 Windows 11 기본 우클릭 메뉴에 표시되며, 많은 파일을 선택해도 모두 전달됩니다.
- **정규식, 일련번호, 조건:** 정규식으로 텍스트를 찾고 캡처 그룹을 치환에 사용할 수 있습니다. 자릿수, 시작 번호, 증가값을 지정해 일련번호를 붙이고, 조건에 맞는 이름에만 트리거를 적용할 수 있습니다.
- **폴더 처리 방식 선택:** 폴더를 추가할 때 폴더 이름 자체를 변경할지, 폴더 안의 파일을 추가할지, 하위 폴더의 파일까지 모두 추가할지 선택합니다. 선택한 방식은 기본값으로 저장할 수 있으며, 설정에서 다시 변경할 수 있습니다.
- **WinUI 기반 네이티브 앱:** Windows의 최신 UI 프레임워크인 WinUI 3로 개발했습니다. 웹 기반 앱이 아니므로 메모리 사용량이 적고 실행이 빠릅니다. 우클릭 메뉴를 포함해 x86, x64, ARM64를 네이티브로 지원하며, 라이트·다크 테마를 따릅니다.
- **다국어 지원:** 한국어, 영어, 일본어, 중국어 간체, 중국어 번체.

## 기존 방식과 다른 점

일반적인 찾아 바꾸기는 한 번에 규칙 하나만 적용합니다. 접두어 삭제, 번호 매기기, 확장자 정리처럼 여러 단계가 필요한 작업은 나눠서 실행해야 하고, 중간에 실수하면 원래 이름으로 되돌리기 어렵습니다.

AT Batch Renamer는 여러 규칙을 트리거 목록 하나로 묶어 한 번에 적용합니다. 실행 전에는 미리보기로 결과와 충돌을 확인하고, 실행 후에는 되돌릴 수 있습니다. 트리거 목록은 파일로 저장해 반복 작업에 다시 쓸 수 있습니다.

## 트리거 동작

| 동작 | 설명 |
|---|---|
| **바꾸기** | 이름 전체 또는 이름 안의 특정 텍스트를 텍스트나 일련번호로 바꿉니다. 특정 텍스트는 일반 텍스트나 정규식으로 찾을 수 있으며, 모든 일치 항목, 첫 번째 항목, 마지막 항목 중에서 바꿀 대상을 선택할 수 있습니다. |
| **추가** | 텍스트나 일련번호를 맨 앞, 맨 뒤, 또는 지정한 글자 수 뒤에 추가합니다. |
| **대소문자 변환** | 모두 대문자, 모두 소문자, 단어 첫 글자 대문자, 첫 글자만 대문자 중에서 선택합니다. |

## 트리거 옵션

- **적용 범위:** 파일 이름, 확장자, 파일 이름과 확장자 중에서 선택합니다. 폴더는 확장자가 없는 것으로 처리하며, `.gitignore`처럼 점으로 시작하는 이름은 전체를 파일 이름으로 처리합니다.
- **정규식:** 바꿀 내용에 `$1`, `$2` 등을 사용해 캡처 그룹을 삽입할 수 있습니다. 정규식 실행에는 시간 제한이 있어 잘못된 패턴 때문에 앱이 멈추지 않습니다.
- **일련번호:** 자릿수, 시작 번호, 증가값을 지정합니다. 번호는 트리거가 실제로 적용된 파일에서만 증가하므로 조건을 사용해도 번호가 건너뛰지 않습니다.
- **목록 순서:** 일련번호는 파일 목록 순서를 따릅니다. 목록은 이름, 수정한 날짜, 만든 날짜, 크기, 확장자 기준으로 오름차순 또는 내림차순 정렬하거나, 드래그로 직접 정렬할 수 있습니다.
- **특정 파일에만 적용:** 파일 이름, 확장자 또는 둘 다를 대상으로 포함, 시작, 끝, 정확히 일치, 정규식 조건을 검사합니다. 조건에 해당할 때와 해당하지 않을 때 중 적용 시점을 선택할 수 있으며, 조건은 앞선 트리거가 적용된 이름을 기준으로 판단합니다.
- **대/소문자 구분:** 찾을 텍스트와 조건에 각각 설정할 수 있습니다.

## 참고 사항

- 되돌리기는 마지막으로 실행한 작업에만 적용되며, 앱을 종료하면 초기화됩니다.
- 폴더 안의 파일을 추가할 때 숨김 파일과 시스템 파일은 제외됩니다.
- 표시 언어 변경은 앱을 다시 시작한 후 적용됩니다.
- 이름을 변경하면 바로 가기, 스크립트, 다른 앱에서 참조하는 경로도 달라집니다. 실행 전에 미리보기를 확인하시기 바랍니다.
